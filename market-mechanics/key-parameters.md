# Market Parameters

Market parameters define the conditions for trading, position health, and vault participation. Use the configuration applicable to the specific market rather than treating an example as a protocol-wide value.

| Parameter category | What readers need to know |
| --- | --- |
| Market identity | Underlying rate, source market, and expiry |
| Position requirements | Funds needed to open or modify exposure |
| Health conditions | Valuation and thresholds used for liquidation |
| Execution limits | Constraints affecting order size and available execution |
| Fees | Basis, timing, and recipient of each applicable charge |
| Vault conditions | Capacity, exposure constraints, and redemption terms |

Distinguish an initial requirement from a maintenance condition, and distinguish a market's configured limit from current available liquidity.

See [Supported Markets](../get-started/supported-markets.md), [Fees](../rates-trading/fee.md), and [Vault Mechanics](vault/README.md).
